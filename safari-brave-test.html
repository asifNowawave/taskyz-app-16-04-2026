🍎 Safari Specific Instructions

Enable Notifications in Safari:

  1. System Preferences: System Preferences → Notifications → Safari → Allow notifications
  2. Safari Settings: Safari → Settings → Websites → Notifications → Allow for this site
  3. Request Permission: Click "Request Permission" button above (must be user-initiated)
  4. Test: Click "Show Minimal Notification" (Safari works best with minimal options)
⚠️ Safari Note: Safari requires minimal notification options (title + body only, no icon/tag).

🦁 Brave Specific Instructions

Enable Notifications in Brave:

  1. Brave Shields: Click Brave icon (lion) → Advanced controls → Allow scripts
  2. Site Settings: Click lock icon → Site settings → Notifications → Allow
  3. Brave Settings: brave://settings/content/notifications → Add this site to "Allow"
  4. System Settings: System Preferences → Notifications → Brave Browser → Allow
  5. Request Permission: Click "Request Permission" button above
  6. Check Console: Open DevTools → Check Console, Info, and Warnings tabs
⚠️ Brave Note: Check all console tabs (Console, Info, Warnings) for logs.
